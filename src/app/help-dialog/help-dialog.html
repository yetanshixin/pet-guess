游戏帮助

游戏目标

通过输入精灵名称进行猜测，找出目标精灵。每次猜测后，你将获得输入精灵的相关信息，帮助你逐步接近答案。

提示颜色说明
绿色高亮 表示该信息与目标精灵完全相同。
黄色高亮 表示该信息与目标精灵接近但不完全相同。
黄色高亮的触发条件
  • 总种族值：与目标精灵的差值 ≤ 50
  • 生命/速度：与目标精灵的差值 ≤ 10
  • 赛季：与目标赛季相邻（差值 ≤ 1）
  • 阶段：与目标精灵的差值 ≤ 1
  • 进化方式：不完全相同但属于相似进化方式（例如使用技能、击败精灵、血脉、突破等）
  • 进化等级：与目标精灵的差值 ≤ 5
  • 平均身高：与目标精灵的差值 ≤ 0.15
  • 平均体重：与目标精灵的差值 ≤ 目标精灵体重的20%
上下箭头的作用

在种族值、赛季、阶段、进化等级、体型等数值类信息中，箭头提示你猜测的方向是否正确：

  • ↑ 表示你输入的数值低于目标，建议下次选择数值更高的精灵。
  • ↓ 表示你输入的数值高于目标，建议下次选择数值更低的精灵。
功能介绍
简单模式
开启后，答案仅会出现最终形态的精灵（同一进化链中阶段最大的精灵），下一轮生效。
随机开局
为首次猜测随机选择一个精灵，适合不想手动输入起手猜测的玩家。
